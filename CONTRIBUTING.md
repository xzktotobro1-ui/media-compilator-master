# Как внести вклад

Спасибо, что хотите улучшить RTX Media Master! Ниже — короткий порядок работы.

## Перед началом

- Посмотрите [README.md](README.md) и [docs/BUILD.md](docs/BUILD.md).
- Для глубинных изменений создайте issue с предложением, чтобы обсудить идею.
- Учтите: бинарники (ffmpeg, модели RIFE) не хранятся в git. Сборка использует
  локальные ассеты, описанные в BUILD.md.

## Рабочий процесс

1. Сделайте fork и новую ветку от `main`: `git checkout -b feature/my-change`.
2. Вносите изменения маленькими коммитами с понятными сообщениями.
3. Перед PR проверьте:
   - `python -m py_compile src/rife_120fps_v3.py`
   - запуск GUI и затронутую страницу
   - короткий тестовый прогон выбранного режима обработки
4. Откройте Pull Request, заполните шаблон и укажите, как проверяли.

## Стиль кода

- Сохраняйте существующий стиль: русские комментарии, типизированные signatures
  где это уже принято,戟 concise naming.
- Не добавляйте новые зависимости без необходимости: программа должна оставаться
  автономной и собираться PyInstaller.
- Для UI-изменений сохраняйте палитру AI Dark и совместимость со светлыми темами.

## Сообщения об ошибках

Используйте шаблон issue и приложите версию, ОС, GPU и логи. Чем больше деталей,
тем быстрее получится воспроизвести проблему.

## Лицензия

Сторонние GPL-компоненты описаны в [NOTICE.md](NOTICE.md).
