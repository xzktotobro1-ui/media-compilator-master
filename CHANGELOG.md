# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [4.1.0] — Novator Edition

### Добавлено
- Полный переход GUI на **Tauri v2 + React + TypeScript + Tailwind CSS + Shadcn UI + Framer Motion + Lucide React** вместо WPF.
- Пять вкладок: «Очередь и Сжатие», «Студия сравнения До / После», «Диагностика и Железо», «Пресеты и Автоматизация», «Журнал и CLI».
- Кастомный заголовок Windows 11 без системной рамки, Mica/acrylic-эффект, бейдж `NOVATOR EDITION v4.1`, прогресс в панели задач и системные уведомления.
- Реальная телеметрия GPU через `nvidia-smi` с честным `N/A`, когда датчик недоступен; живые спарклайны по истории опросов.
- Реальные метаданные `ffprobe`, матрица кодеков из `ffmpeg -encoders`, паспорт системы через CIM/vulkaninfo.
- Локальный HTTP-сервер с поддержкой `Range`/`206 Partial Content` и токеном для плавного стриминга 4K/120fps в WebView2.
- Синхронный comparitor: шторка, зум 100–400%, покадровая перемотка, скорость, объективные метрики SSIM/PSNR через `ffmpeg`.
- Watch Folder на базе `notify`: новые видеофайлы автоматически попадают в очередь.
- Расчёт целевого битрейта по реальной длительности и аудиодорожкам; мини-таймлайн обрезки `--ss`/`--to`; тест 5 секунд.
- NSIS-установщик `setup.exe` с выбором папки, ярлыками и опциональной интеграцией в контекстное меню Windows.

### Изменено
- Движок поставляется как headless sidecar `rtx_engine` вместе с `ffmpeg`/`ffprobe` и runtime-библиотеками; SPA общается с Rust-командами через IPC.
- Палитра: фон `#09090B`, стеклянные карточки `#111114`/`#18181C`, акцент RTX Emerald → Cyan, Inter + JetBrains Mono с `tabular-nums`.
- Журнал сокращён до реального потока `engine-log` с фильтрами ALL/INFO/WARN/ERROR, поиском, экспортом `.txt` и копированием CLI-команды.

### Исправлено
- Стили Tailwind v4 загружались некорректно из-за старых директив v3 — переход на `@import "tailwindcss"`.
- Удалены все неработающие и моковые элементы управления: выдуманные значения GPU, фейковый прогресс, неподдерживаемые флаги encodes/audio/action.
- Сборка `setup.exe` включает реальные sidecar-бинарники `rtx_engine`, `ffmpeg`, `ffprobe`, `rife-ncnn-vulkan`, а также `_internal/`, `models/` и `vcomp140.dll` из релиза v3.5 — рядом с `rtx-media-master.exe`.
- Подправлена шапка: уменьшены горизонтальные отступы кнопок вкладок, GPU-капсула ограничена `max-w-[220px] truncate`, кнопки управления окном всегда видимы.
- В выпадающих списках док-бара добавлен `pr-7`, текст больше не перекрывается стрелкой.

## [4.0.0] — 2026-11-28

### Добавлено
- Новый интерфейс на **C# / .NET 8 / WPF** вместо Tkinter: собственный заголовок, капсула GPU, стеклянные карточки, градиент RTX Green → Cyan, Mica/акрил.
- Очередь с Drag & Drop, поиском, асинхронными миниатюрами, метаданными `ffprobe`, бейджем VFR и стадиями прогресса.
- Тест 5 секунд с реальным превью-рендером и диалогом сравнения «До / После».
- Менеджер пресетов, действие после завершения и пили-переключатели FPS/пресета/кодека/Enhance.
- Фоновая диагностика GPU, радиальный индикатор, полоса VRAM, спарклайны и таблица компонентов через `nvidia-smi`.
- Журнал с подсветкой INFO/WARNING/ERROR, поиском, экспортом `.txt`, копированием CLI-команды и проверкой `ffprobe`.
- Диалог «О программе» с версией, автором, GitHub, MIT, NOTICE.md и проверкой обновлений через GitHub Releases.

### Изменено
- Вычисления вынесены в отдельный headless-процесс `rtx_engine.exe` (PyInstaller); при отсутствии GUI запускал `python -u rtx_media_master_v35.py`.
- Сборка переведена на `Microsoft.NET.Sdk`; `build.ps1` поддерживает переиспользование готовых сборок.
- Улучшена обработка ошибок, потокобезопасность UI и маршалинг событий движка в UI-поток.
