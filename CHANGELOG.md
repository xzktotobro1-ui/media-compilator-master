# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [3.5] — 2026-11-26

### Добавлено

- Полноценное GUI-приложение v3.5 со встроенным движком: настройки кодека (`auto/av1/hevc/vvc/h264`), пресета (`compact/balanced/quality`), GPU, `Enhance`, целевого FPS вверх/вниз; прогресс и итоговая статистика размера до/после в строке состояния.
- CLI сохранён как внутренний бэкенд `--headless` для автоматизации и диагностики; основным продуктом остаётся оконная программа с MSI-установщиком.
- Движок: диагностика FFmpeg/FFprobe/RIFE/Vulkan, модель `rife-v4.6`, нормализация VFR→CFR, перекрывающиеся чанки с обработкой сцен-резов `scdet`, точные длительность и число кадров.
- Современные кодеки с 10-bit: AV1 (`libsvtav1`, `av1_nvenc`), HEVC (`libx265`, `hevc_nvenc`), VVC (`libvvenc`), H.264 как фолбэк; корректные CQ/mbr/bitrate_cap.
- `--enhance`: `bwdif`, `zscale`, `hqdn3d`, `cas=0.25` для деинтерлейса, цвета и лёгкой резкости.

### Исправлено

- `av1_nvenc`: правильная шкала CQ 0–63 (38/34/30 вместо почти lossless 26), явные `-b:v` и `-maxrate`.
- `libsvtav1`: предел битрейта задаётся через `mbr=` внутри `-svtav1-params` (в CRF-режиме `-maxrate` игнорируется).
- Временные каталоги чанков гарантированно удаляются через `TemporaryDirectory` и `try...finally`.
- Windowed-сборка: корректная работа `--headless` при `sys.stdout=None`, отдельный crash-лог.

### Проверено

- 30 → 60 FPS, HEVC Main 10 (`libx265`, `--enhance`): 4.000 с, ровно 240 кадров, размер 0.576x от исходного.
- 30 → 120 FPS, AV1 (`libsvtav1`, capped CRF 28): 4.000 с, 480 кадров, размер 0.628x.
- 30 → 24 FPS, VVC (`libvvenc`): 4.000 с, 10-bit, размер 0.224x.
- GUI запускается с заголовком «RTX Media Master v3.5 - Video Interpolator»; MSI устанавливается в `C:\Program Files (x86)\RTX Media Master`.

## [3.1.1] — 2026-11-25

### Исправлено

- Запуск MSI-версии больше не падает с `PermissionError [Errno 13]` при создании
  `session_runtime.log` в `Program Files`: журнал, настройки, crash-лог и временные
  архивы перенесены в доступный для записи каталог `%APPDATA%\RTX Media Master`.
- Настройки из прежнего расположения автоматически переносятся при первом запуске.
- Если бинарники отсутствуют в каталоге программы, они скачиваются в пользовательский
  каталог без прав администратора.
- Файловый лог при недоступности больше не блокирует запуск программы.

- Улучшенная визуальная подача интерфейса: карточки, отступы, типографика.

## [3.0.0] — 2026-11-25

### Добавлено

- Автономная сборка PyInstaller и MSI-установщик: Python не нужен.
- GUI в стиле Windows 11: NavigationView, CommandBar, страницы «Очередь»,
  «Диагностика», «Параметры», «Журнал», темы AI Dark / Windows / светлая / тёмная.
- Режимы обработки: RIFE ncnn-vulkan (Vulkan GPU), Turbo GPU, AI CPU minterpolate.
- Очередь файлов с поиском, инспектор видео, прогресс и ETA.
- Диагностика комплектующих и телеметрия GPU/VRAM через nvidia-smi.
- Профили «качество ↔ размер», NVENC/AMF/AV1 с программным фолбэком.
- WiX-генератор и скрипт `build.ps1` для воспроизводимой сборки MSI.

### Исправлено

- Определение доступных энкодеров: NVENC/AMF теперь корректно обнаруживаются.
- Поиск моделей RIFE внутри вложенных папок архива.
- Прогресс кодирования через `-progress pipe:1`, корректный ETA.
- Сохранение настроек вынесено в главный поток GUI.
-AV1: корректные параметры libsvtav1/libaom-av1 и фолбэк SVT → AOM.
- Обработка битых `settings.json` и отмены операций.

### Известные ограничения

- AV1-кодирование на RTX 3050 выполняется программно (libsvtav1) — медленнее NVENC.
- Для RIFE необходим GPU с поддержкой Vulkan.
